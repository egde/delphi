# v0.3.0: Serverless Compute + DBR Compatibility Guide

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow Delphi to target serverless compute on Databricks via databricks-connect, and provide clear guidance when there's a DBR/databricks-connect version mismatch.

**Architecture:** Make `cluster_id` optional in ConnectionConfig. When `serverless=true`, use `DatabricksSession.builder.remote(serverless=True)` instead of passing a cluster_id. Wrap session creation with a try/except that catches version mismatch errors and provides actionable guidance.

**Tech Stack:** databricks-connect (existing), databricks-sdk (existing)

**Spec:** Based on databricks-connect 18.x source code analysis. Key facts:
- `cluster_id` and `serverless` are mutually exclusive in `DatabricksSession.builder.remote()`
- Serverless internally sets `serverless_compute_id = "auto"`
- Minimum DBR for serverless: 16.0
- Version validation: databricks-connect major.minor must be <= DBR major.minor
- Common errors: "Unsupported combination of Databricks Runtime & Databricks Connect versions", "Can't set both cluster id and serverless"

**Branch:** `v0.3.0-dev`

```python
def get_spark_session(
    config: DelphiConfig | None = None,
    profile: str | None = None,
):
    from databricks.connect import DatabricksSession

    if config is None:
        return DatabricksSession.builder.getOrCreate()

    conn = resolve_connection_config(config, profile)

    if not conn.host:
        return DatabricksSession.builder.getOrCreate()

    # Need either cluster_id or serverless
    if not conn.cluster_id and not conn.serverless:
        return DatabricksSession.builder.getOrCreate()

    try:
        if conn.serverless:
            builder = DatabricksSession.builder.remote(
                host=conn.host,
                serverless=True,
            )
        else:
            builder = DatabricksSession.builder.remote(
                host=conn.host,
                cluster_id=conn.cluster_id,
            )

        if conn.auth_type == "pat" and conn.token:
            builder = builder.token(conn.token)
        elif conn.auth_type == "env":
            token = os.environ.get("DATABRICKS_TOKEN", "")
            if token:
                builder = builder.token(token)

        return builder.getOrCreate()

    except Exception as e:
        _handle_connect_error(e)
        raise
```

```python
def _handle_connect_error(error: Exception):
    """Provide actionable guidance for common databricks-connect errors."""
    msg = str(error)

    if "Unsupported combination" in msg and "Databricks Runtime" in msg:
        logger.error(
            "databricks-connect version doesn't match the Databricks Runtime version.\n"
            "\n"
            "To fix this, install the databricks-connect version that matches your DBR:\n"
            "  pip install 'databricks-connect==<DBR_MAJOR>.<DBR_MINOR>.*'\n"
            "\n"
            "For example:\n"
            "  DBR 15.4 -> pip install 'databricks-connect==15.4.*'\n"
            "  DBR 16.1 -> pip install 'databricks-connect==16.1.*'\n"
            "  DBR 18.1 -> pip install 'databricks-connect==18.1.*'\n"
            "\n"
            "Find your DBR version in Databricks UI: Compute -> your cluster -> Databricks Runtime Version.\n"
            "For serverless, use the latest databricks-connect version.\n"
            "\n"
            "See docs/databricks-connect-guide.md for details."
        )

    elif "Can't set both cluster id and serverless" in msg:
        logger.error(
            "Both cluster_id and serverless are set in your config.\n"
            "Use one or the other:\n"
            "  - For a cluster:    cluster_id = \"your-cluster-id\"\n"
            "  - For serverless:   serverless = true  (remove cluster_id)\n"
        )

    elif "pyspark and databricks-connect cannot be installed" in msg:
        logger.error(
            "pyspark and databricks-connect conflict.\n"
            "Fix: pip uninstall -y pyspark pyspark-connect pyspark-client databricks-connect\n"
            "Then: pip install databricks-connect\n"
        )

    elif "Cluster id or serverless are required" in msg:
        logger.error(
            "No compute target specified.\n"
            "Set either cluster_id or serverless=true in delphi.toml,\n"
            "or run 'delphi setup' to configure.\n"
        )
```
